３．作成ツール紹介

　　ゲームで良く遊ばれる方なら、１度は自分でゲームを作ってみたいと思われる方も多いと思います。このバスケットゲーム程度のゲームなら、特別な設備やソフトがなくても作ることが可能です。
　　最近では、ツクールシリーズ等、ゲーム開発ツールも販売されるようになり、インターネットでは素晴らしいフリーソフトが沢山公開されるようになってきました。あなたも、ゲーム作りに挑戦してみませんか？



3.1　Ｃコンパイラ

　　自作のゲームを作る場合、作成プログラム言語を何にするかをまず決めなくてはなりません。「ひぐらしのなく頃に」は、高橋直樹様の「ＮＳｃｒｉｐｔer」が使用されています。また、市販の「ツクール」シリーズを利用するのも手です。
　　本バスケットゲームでは、C++という言語を用いています。
　　C言語は、パソコンの性能をほとんど限界まで引き出せる、つまり自分の作りたいゲームを制限なく、思いのままに作れるという利点があります。
　　ただし、C言語は難しい上に、基本的な事以外は誰も教えてくれない、教科書やネットを見ても、まったく上達しないという、完全な独学でプログラミングを身に付けるしかないという欠点もあります。
　　Windows用Cコンパイラは、VisualCが一般的ですが、安く済ませようとするなら、無料のBorland C++がインターネットで公開されていますので、これを試してみるのも良いでしょう。

　　使用したCコンパイラ：　VisualC++5.0


3.2　DirectX　SDK

　　最近のWindowｓゲームは、DirectXで動作するものがほとんどです。DirectX　SDKは、DirectXを使用するプログラムを開発するためのツールです。microsoftのホームページから無料で配布されています。C言語さえマスターしていれば、DirectX SDKプログラミングに関するホームページは沢山ありますので、それらを参考に試行錯誤していけばプログラミングできるようになります。DirectXには、いくつかのバージョンが存在します。本バスケットゲームでは、DirectX7.0a SDK を用いています。バージョン7.0は、すでに時代遅れなのですが、ほとんどのパソコンで動作しますし、一番基本的なものですので、私は良く使用しています。



3.3　ポリゴンモデリングツール

　　３Ｄのポリゴンゲームを作成しようと考えた場合、必ず必要になるのがポリゴンのモデリングツールです。世の中には様々なモデリングツールがありますが、本バスケットゲームでは、Metasequoia LE というソフトを利用しています。これまた無料です。Metasequoiaというソフトは製品版もあるのですが、無料版でも十分すぎる位の機能があります。（ファイナル○ァンタジーのポリゴンモデルも、モデリングはMetasequoiaが使われているという話を聞いたことがあります。）
　　ポリゴンキャラ作成には、モデリングの他にテクスチャの貼り付け（マッピング）等も必要なのですが、私は無料版のMetasequoia LE で全部やってしまっています。Metasequoiaについての解説も、たくさんのホームページで公開されていますので、そちらを参考にしてみてください。
　　３Ｄポリゴンキャラのデザイナーは、結構求人があるみたいですね。趣味でやる分にも、とても面白いです。フィギュアみたいに好きなポーズをとらせる事ができますし、いくらでも自分の好きなキャラを作れる上に、パソコン上で動かせ、胸を大きくしたりなんて事もできますので…。



3.4　ポリゴンモーションエディタ

　　ポリゴンを作ったら、当然ぐりぐり動かしてみたくなりますよね？これも様々なツールがでていますが、私は自作のツールを使っています。Ｃ言語で組んだものですので、当然無料です。まず、ボーン処理といって、ポリゴンの関節を設定して、各関節をどれくらいの時間でどのくらい動かすかを決定しなければなりません。自分のゲームに取り込むためには、この辺りから自作する必要がでてきます。原理については、「ＤｉｒｅｃｔＸ、ボーン処理」等でググレば見つかると思います。



3.5　グラフィックツール

　　パソコンでゲームを作る以上、ほとんどのゲームで必要になるのがグラフィックツールです。これも、無料のツールが沢山でていますが、ゲームのクオリティを高めようと思ったら、市販の高級ソフトが必要になってきます。私はＰｈｏｔｏｓｈｏｐを用いています。ゲームに限らず、漫画や絵を描く場合にも使えますので、すでにもっていらっしゃる方も多いかと思います。ポリゴンキャラを少しでも見栄えの良いものにするためには、テクスチャを綺麗に仕上げる必要があります。Ｐｈｏｔｏｓｈｏｐは様々なフィルタが使えるので、非常に重用してます。まぁ、中古パソコンが１台買えてしまうくらい高額なソフトなのが難点ですが…。あっ、でも絵に才能のある方でしたら、無料のツールでも十分に使えると思います。ホームページ、雛見沢村観光案内のお絵描き掲示板をみてると、これ本当にしぃペインタで描いたのっ？ってくらい上手い方がたくさんいらっしゃいますもんね。



3.6　まとめ

　　以上、述べましたとおり、特別な設備やお金をかけなくても、ポリゴンゲームは作れます。が、ポリゴンに限らず、ゲーム作りは非常に根気が要ります。プログラミングが好きだぁ！！という方、もしくは＊んでも自作のゲームを作ってやるぞぉ！！という方でなければなかなか難しいかもしれません…。
　　ただ、最近は、「ツクール」シリーズ、他にも「ＮＳｃｒｉｐｔer」等のすばらしいソフトが公開されてきていますので、熱意と情熱とすばらしいアイディアがあれば、凄いゲームが作れるようになってきています。ゲームを作るのは、遊ぶのとはまた違う、なんともいえない面白さがあります。クリエイトの楽しさにハマってみませんか？
　「ひぐらし」関連のすばらしい２次創作ゲームを作ってくれるクリエーター様が登場してくださることを期待しています。
