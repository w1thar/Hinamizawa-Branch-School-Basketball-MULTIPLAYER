１．インストール方法

　　この取説、"バスケ取説.htm"のあるフォルダ内のファイル、1."basket_v101.exe"、2.フォルダ"basket"、および、この取説　3."バスケ取説.htm"を、”ひぐらしのなく頃に”（体験版、製品版どちらでもＯＫ）をインストールしたフォルダの中に移動します。　あとは"basket_v101.exe"を実行することで起動します。　

上記の３つのファイルを、”ひぐらしのなく頃に”のフォルダにコピーする


2.1　アンインストール方法

　　レジストリ等は一切使っておりません。コピーしたファイルを削除するだけで結構です。


2.2　バージョンアップ

　　大きい改編があった場合には、雛見沢村観光案内様のホームページの２次創作掲示板にアップロードさせていただく予定ですが、ちょっとしたバージョンアップは、ホームページ「ひぐらしド♪」にて公開する予定です。なかなか時間が取れなくて、遅々とする可能性が大ですが、ご了承くださいませ。
